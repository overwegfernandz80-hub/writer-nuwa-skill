# Writer Nuwa Examples

This directory contains examples of generated Writer Skills. Each active example should represent an author's writing system rather than a general persona or viewpoint.

## Required Example Structure

```text
writer-author/
├── SKILL.md
├── FIDELITY.md
└── references/
    └── research/
        ├── 01-corpus.md
        ├── 02-linguistic-dna.md
        ├── 03-narrative-dna.md
        ├── 04-rhetoric-imagery.md
        ├── 05-poetics-criticism.md
        └── 06-period-contrast.md
```

## Required Properties

- The corpus, period, genre, language, and edition are explicit.
- Literary descriptions are converted through Observation, Evidence, Mechanism, Trigger, Operation, and Failure Condition.
- Rules support both revision and original writing.
- Fidelity validation includes reconstruction, unseen topic, ablation, anti-caricature, and contrast tests.
- Living-author examples prioritize analysis and writing education over high-fidelity imitation.
- Translation effects are separated from original-language author features.

## Legacy Archive

The former person-oriented examples are retained in [`examples-legacy/`](../examples-legacy/) for historical reference only. They are not Writer Nuwa output examples and should not be used as the active Writer corpus.
